#claude-status-bar

A status line for Claude Code: folder, git branch, model, effort, and usage windows that are actually correct.

session
a coloured dot and six characters, so you can tell sessions apart — the same mark keyboard-display draws on its panel
where
folder and git branch; the branch gives way first on a narrow terminal
model
model and effort level
5h / wk
usage bars with time until reset, kept current across every open session instead of each one's stale snapshot
installsh
$curl -fsSL https://xiaweiliu.com/claude-status-bar/install.sh | sh

Needs only python3 3.8+. Leaves your other settings alone; run it again to upgrade.

Linux and macOS. On macOS Claude Code keeps its login in the Keychain, so the background usage refresh is skipped there and the bars update from your sessions instead. Source and documentation on GitHub
